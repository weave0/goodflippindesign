# Good Flippin News Art Prompt Pack

## Purpose

Create a small set of cinematic, friendly, storybook-news images for the Good Flippin News placeholder page. The art should feel like a fictional behind-the-scenes newsroom where Shariff, DJ Z, Heavy Moose, and the neighborhood cats are building a joy-forward news operation.

## Visual Direction

- Tone: warm, playful, premium, quietly futuristic
- Look: polished editorial illustration with cinematic lighting, soft depth, clean silhouettes, and rich texture
- Palette: midnight blue, warm amber, muted teal, cream, gold, soft coral, ink black
- Composition: readable at thumbnail size, but detailed enough for a hero panel
- Avoid: flat stock-photo realism, generic newsroom clichés, overly cute cartoon style, gritty satire, text-heavy poster design

## Character Anchors

- Shariff: confident cat editor / newsroom lead, calm expression, warm authority, hopeful angle on every story
- DJ Z: rhythm-and-momentum operator, audio / beat / broadcast energy, creative gear, cool but friendly presence
- Heavy Moose: large, industrious production lead, practical hands-on builder, grounded and steady
- Neighborhood cats: photo scouts, fact-checkers, snack auditors, small ensemble of helpers adding charm and motion

## Recommended Deliverables

1. Hero wide image for the top of the page
2. Shariff-centered newsroom scene
3. DJ Z broadcast / rhythm desk scene
4. Heavy Moose production scene
5. Ensemble “back room crew” illustration

## Master Style Prompt

Use this as the base for all images:

Cinematic editorial illustration with gentle fantasy realism. A fictional newsroom for a joyful news brand, lit by warm amber practical lights and cool teal interface glow. Anthropomorphic cats work behind the scenes with purpose and personality. Rich textures, expressive faces, layered environment details, premium composition, clean readable silhouettes, subtle futuristic equipment, inviting and optimistic mood. No text, no logos, no watermark.

## Variant Prompt Notes

- If an image feels too literal, push it toward “editorial illustration” and “cinematic storybook realism.”
- If it feels too cartoonish, add “premium texture,” “soft depth of field,” and “layered environment details.”
- If it feels too dark, add “hopeful,” “warm amber practical lights,” and “optimistic mood.”
- If it feels too generic, name the characters explicitly: Shariff, DJ Z, Heavy Moose, neighborhood cats.

## Iteration Order

1. Generate the hero wide image first.
2. Generate Shariff, then DJ Z, then Heavy Moose.
3. Generate the ensemble scene last after the character look is locked.
4. Once the style is consistent, refine with one pass of color/lighting adjustments.

## Final Check

Before publishing, confirm each image:

- reads clearly at small size
- feels connected to the same world
- keeps the characters recognizable
- avoids generic newsroom or stock-photo vibes
- stays warm, hopeful, and fictional
