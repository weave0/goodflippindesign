# MVP Launch Checklist

Use this for seed and MVP sites before deployment or public promotion.

## Positioning

- [ ] First viewport says what the site is and who it is for.
- [ ] Primary CTA is visible without hunting.
- [ ] Secondary CTA routes to a useful ecosystem surface.
- [ ] Page title and meta description are specific.

## Ecosystem

- [ ] Good Flippin Design or Good Flippin Vibes relationship is clear.
- [ ] Ecosystem footer links are present.
- [ ] Legal/privacy links are present when user data or payments are involved.
- [ ] Supporter/sponsor language is appropriate for the site's trust level.

## Technical

- [ ] Canonical URL is set when the deployment target is known.
- [ ] Images have useful alt text.
- [ ] Interactive controls are keyboard usable.
- [ ] Mobile layout works at 375px and 768px.
- [ ] No console errors in the first interaction path.

## Measurement

- [ ] CTA can be measured through analytics, UTM, form submission, or link target.
- [ ] `brands.json` has `stage`, `primaryCta`, `secondaryCta`, `deployment`, and `ops.nextAction`.
- [ ] Site brief is current.
