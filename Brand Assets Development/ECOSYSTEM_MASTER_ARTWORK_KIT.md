# Ecosystem Master Artwork Kit

**Status:** Ready for verified public-canon generation pass
**Purpose:** Create one flagship artwork image that compresses the full Good Flippin Design universe into a single coherent visual system.
**Scope:** The verified public canon led by Good Flippin Design, Good Flippin Vibes, AI Aimate, CultureSherpa, CitizenApproved, GlobalDeets, and Foxyana, with supporting public properties and internal platforms encoded as secondary layers.

---

## The Constraint

You do **not** want a collage of logos.

You want one image that reads correctly at three distances:

1. **From far away** it feels like one premium artwork.
2. **At mid distance** it reveals a connected ecosystem.
3. **Up close** it rewards inspection with specific references to the products, art, data, culture, music, and tooling you have built.

That means the image needs a **single governing composition** with many embedded motifs, not a wall of unrelated symbols.

---

## The Core Strategy

Use this framing for every generation:

**One studio. Many expressions. One visual field.**

Translate the ecosystem into five visual layers:

1. **Central Engine**
   Good Flippin Design as the maker layer: architecture, code, systems, precision, orchestration.
2. **Human / Cultural Layer**
   Good Flippin Vibes, CultureSherpa, Minnesota Peace, Brett Lee Weaver, community, healing, identity, people.
3. **Product / Intelligence Layer**
   AI Aimate, CitizenApproved, GlobalDeets, analytics, civic tech, learning, maps, dashboards, search, automation.
4. **Creative Canon Layer**
   Foxyana, the music catalog, visual storytelling, world-building, mythic character energy.
5. **Internal Infrastructure Layer**
   SummitView, Weave, ThyOwn, CASHMONEY, hidden scaffolding, pipelines, data systems, finance and operations.

Priority rule:

- Let the live studio site and Cloudflare-verified public properties determine what gets the most visual real estate.
- Let internal projects enrich the substructure, not dominate the composition.
- Let unresolved slots like AETC stay peripheral unless explicitly promoted.

The final image should make these layers feel like one living organism.

## Recommended Composition Model

Use this as the default unless a later concept clearly beats it.

### Model A: Constellation City

- A luminous central structure represents Good Flippin Design.
- Distinct districts or orbiting chambers represent each major product or brand.
- Pathways, rivers, transit lines, fiber routes, or constellations connect them.
- Human, cultural, and musical motifs are embedded in the terrain, atmosphere, and architecture.
- Data, maps, dashboards, and civic structures appear as artifacts inside the world rather than UI screenshots.

This model works because it can hold everything without looking like a poster board.

### Model B: Mythic Systems Atlas

- Build one monumental diagram-like painting.
- Use a symbolic world map / circuit map / celestial atlas structure.
- Each brand becomes a biome, emblem, gateway, or current flowing through the whole.

Use this if you want the result to feel more editorial, archival, or museum-grade.

### Model C: Living Cathedral of Work

- One giant interior or impossible architecture.
- Every arch, screen, mural, banner, artifact, or portal encodes part of the ecosystem.

Use this if you want a more emotional, sacred, legacy-making image.

## Visual Translation Rules

### Rule 1: No literal logo salad

Do not place every brand as a logo badge.

Instead:

- Turn each brand into a motif, district, material, or energy signature.
- Allow at most 2-3 visible wordmarks or glyph-level callbacks if needed.

### Rule 2: Use one dominant palette with controlled accents

Base palette:

- Charcoal / deep night for the field
- Luminous neutrals for structure

Accent families already present in the ecosystem:

- Cyan / teal for AI, data, intelligence
- Amber / gold for warmth, culture, portfolio, origin energy
- Green for culture, growth, healing, exploration
- Blue for civic trust and product clarity
- Violet for systems, analytics, and connective intelligence
- Red-gold ember for Foxyana and mythic creative energy

### Rule 3: Convert products into environments

Examples:

- AI Aimate becomes a glowing learning lattice, semantic pathways, or intelligent observatory.
- CultureSherpa becomes map contours, textiles, artifacts, human silhouettes, atlas routes.
- CitizenApproved becomes civic pillars, public ledgers, signal towers, transparent chambers.
- GlobalDeets becomes floating dashboards, data skylines, gridwork, charts as architecture.
- Foxyana becomes wind, fabric, amber fire, folklore geometry, sound waves in the sky.
- Heavy Moose becomes performance mass, red stage thunder, bass-weighted structures.
- Red Leopard of St. Paul becomes prowling crimson motion and nightlife energy.
- Lowertown St Paul becomes brick corridors, streetlight geometry, warehouse warmth, urban district texture.

### Rule 4: Make the image emotionally legible

The image should say:

"This is a life’s body of work built by one mind that moves between code, culture, community, systems, art, and future-making."

## Prompt Construction Formula

Every strong prompt should have these blocks in this order:

1. **Command block**
   Tell the model to create one single cohesive hero artwork, not a collage.
2. **Composition block**
   Define the governing structure: constellation city, atlas, cathedral, etc.
3. **Narrative block**
   Explain that the image represents an entire interconnected ecosystem of work.
4. **Motif block**
   Encode each core brand using short visual translations.
5. **Style block**
   Set medium, finish, lighting, realism level, and emotional tone.
6. **Exclusion block**
   Ban mockups, cheap branding clichés, UI screenshots, text overload, and collage behavior.
7. **Output block**
   Specify aspect ratio, resolution target, inspection detail, and clean exportability.

Use the companion template in [Brand Assets Development/ECOSYSTEM_MASTER_ARTWORK_PROMPT_TEMPLATE.md](./ECOSYSTEM_MASTER_ARTWORK_PROMPT_TEMPLATE.md).

This is the recommended first generation direction.

### Direction: Cinematic Mythic Systems Painting

- Medium: cinematic digital painting with editorial-grade detail
- Composition: constellation city / world-engine hybrid
- Mood: premium, intelligent, warm, visionary, slightly sacred
- Detail density: high enough to reward zooming, low enough to remain unified
- Text usage: none inside the image
- Branding usage: symbolic, not logo-forward

This direction gives you the highest chance of fitting the entire canon into one image without it becoming corny.

## Generation Workflow

### Step 1: Update the manifest

Before any generation pass:

- Open [Brand Assets Development/ecosystem-artwork-manifest.json](./ecosystem-artwork-manifest.json)
- Confirm the verified public canon is current
- Add any missing supporting or edge entities you want represented
- Only fill in AETC if it becomes canonically defined

### Step 2: Choose one composition model

Pick one:

- Constellation City
- Mythic Systems Atlas
- Living Cathedral of Work

Do not mix all three on the first pass.

### Step 3: Build the prompt from the template

- Keep the core composition constant
- Swap only the motif details and medium if needed
- Keep exclusions strict
- Start from [Brand Assets Development/ECOSYSTEM_MASTER_ARTWORK_FINAL_PROMPT.txt](./ECOSYSTEM_MASTER_ARTWORK_FINAL_PROMPT.txt) unless you have a specific reason to branch

### Step 3.5: Use the runnable generator

- Run [Brand Assets Development/scripts/generate-ecosystem-master-art.py](./scripts/generate-ecosystem-master-art.py)
- Default run generates one master candidate using the final prompt file
- Use `--dry-run` first if you only want an environment and prompt check

### Step 4: Generate three variants max

Use three passes with minimal controlled variance:

1. Balanced ecosystem version
2. More human/cultural version
3. More systems/data/mythic version

If you do more than three loose prompts, quality usually degrades into randomness.

### Step 5: Score the outputs

Judge each image on:

- Unity
- Ecosystem coverage
- Emotional accuracy
- Beauty at full view
- Detail reward on zoom
- Extractability into future derivative assets

### Step 6: Lock one master image

Once one image wins:

- Upscale carefully if needed
- Create crop derivatives for banner, poster, and social use
- Optionally create an annotated companion map that explains references

## What To Avoid

- Literal app screenshots floating in space
- Every brand represented as a separate box or badge
- Too many readable words inside the image
- Obvious “tech poster” clichés: random holograms, fake HUD junk, generic neon cyberpunk
- Flat corporate vector style if the goal is legacy artwork
- Over-indexing on one product and losing the ecosystem
- Attempting to depict every detail literally instead of symbolically

An image is strong enough to keep only if all of these are true:

- It looks like one serious artwork, not a marketing collage.
- Good Flippin Design feels central without flattening everything else.
- Foxyana and the broader creative canon are present without hijacking the image.
- GlobalDeets, AI Aimate, CultureSherpa, and CitizenApproved feel distinct.
- The image contains human warmth, not just technical spectacle.
- The hidden infrastructure layer is felt, even if not obvious at first glance.
- The image suggests legacy, not just current projects.
