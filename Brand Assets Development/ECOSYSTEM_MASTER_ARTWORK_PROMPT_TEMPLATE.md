# Ecosystem Master Artwork Prompt Template

Use this template after updating [Brand Assets Development/ecosystem-artwork-manifest.json](./ecosystem-artwork-manifest.json).

The current priority order is:

1. Externally verified public canon from the live studio site and Cloudflare Pages
2. Supporting public properties that deepen the world without stealing the composition
3. Internal infrastructure as hidden understructure
4. Unresolved slots like AETC only as optional edge references

```text

Create a [CHOOSE ONE: constellation city / mythic systems atlas / living cathedral of work] in which one central luminous structure represents Good Flippin Design as the maker, systems, and orchestration layer.

This image should depict a life's body of work spanning web development, AI education, cultural exploration, civic technology, analytics, portfolio ecosystems, music mythology, founder vision, and internal infrastructure. It should feel interconnected, intentional, warm, intelligent, and slightly sacred. The visible foreground should be driven first by the externally verified public ecosystem, not by every local directory or speculative project.

- Minnesota Peace: calm mediation spaces, balance, listening, resolution, restorative stillness
- Heavy Moose: public performance mass, stage heat, rhythmic thunder, red kinetic force
- Red Leopard of St. Paul: nocturnal creative velocity, red motion trails, prowling artistic pulse
- Lowertown St Paul: place-based district, orange streetlight geometry, neighborhood gravity, brick-and-corridor civic texture
- Brett Lee Weaver: unseen authorial connective intelligence across the whole world

- Good Flippin Yikes and other edge properties: tiny unstable edge-signals or peripheral glints only
- AETC and future works: only if needed, suggested as subtle reserved zones, dormant portals, unopened districts, or emerging structures at the horizon

STYLE:
- Cinematic digital painting
- Editorial-grade concept art
- Museum-quality composition
- High detail on zoom, strong silhouette from a distance
- Dark atmospheric base with disciplined accent colors: cyan, teal, amber, gold, green, blue, violet, ember red

MOOD:
Visionary, generous, intelligent, expansive, culturally alive, emotionally precise, legacy-building

EXCLUDE:
- no logo collage
- no app mockups
- no phone screens or laptop presentations
- no generic futuristic HUD clutter
- no readable text

- no random disconnected symbols

- no visual chaos

OUTPUT:
- ultra-detailed master artwork
- aspect ratio [16:9 or 3:2]
- composed for both full-scene viewing and close inspection
- clean enough that future crops can pull distinct sub-scenes from the master image

PRIORITY CONTROL:
- Spend the most visual weight on Good Flippin Design, Good Flippin Vibes, AI Aimate, CultureSherpa, CitizenApproved, GlobalDeets, and Foxyana.
- Spend secondary visual weight on Minnesota Peace, Brett Lee Weaver, Heavy Moose, Red Leopard of St. Paul, and Lowertown St Paul.
- Keep infrastructure mostly implicit.
- Do not let unresolved slots dominate the image.
```

## Prompt Compression Rule

If a model starts losing coherence, cut detail in this order:

1. Remove some supporting/internal systems.
2. Keep only one phrase per brand.
3. Preserve the composition block and exclusion block.
4. Never remove the instruction that it must be one unified artwork rather than a collage.
