## 📏 Technical Specifications Reference

### **Color System**

```css
/* Primary Brand Colors */
--brand-dark-bg: #0d0d0d;        /* Deep charcoal, primary backgrounds */
--brand-dark-elevated: #151515;  /* Subtle elevation layer */
--brand-dark-card: #1a1a1a;      /* Card/content backgrounds */

--brand-light-primary: #f5f5f5;  /* Primary text, light elements */
--brand-light-muted: #8a8a8a;    /* Secondary text (WCAG AA 4.5:1) */
--brand-light-accent: #e0e0e0;   /* Highlight elements */

/* Accent Colors (choose ONE primary accent for logo glow) */
--accent-wellness-teal: #10b981;  /* Growth, trust, health */
--accent-innovation-purple: #8b5cf6;  /* Intelligence, creativity */
--accent-warm-amber: #fbbf24;    /* Energy, optimism, warmth */

/* CMYK Equivalents (for print) */
Dark BG: C85 M79 Y79 K93
Light Primary: C0 M0 Y0 K4
Wellness Teal: C64 M0 Y46 K0
Innovation Purple: C45 M64 Y0 K0
Warm Amber: C0 M24 Y85 K2
```

### **Typography System**

```
Primary Font: Inter
- Weights: 300 (Light), 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
- Usage: All body text, headings, UI elements
- Web: Google Fonts CDN
- Print: Download licensed OTF/TTF

Monospace Font: JetBrains Mono
- Weights: 400 (Regular), 500 (Medium)
- Usage: Code snippets, technical labels, process numbers
- Web: Google Fonts CDN
- Print: Download licensed OTF/TTF

Fallbacks: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
```

### **Logo Clear Space**

```
Minimum clear space around logo:
- All sides: 1x the height of the logo icon
- Example: If logo is 100px tall, maintain 100px clear space on all sides
- Exception: Can be reduced to 0.5x for small digital placements (favicons)

Minimum sizes:
- Digital: Never smaller than 16x16px (favicon exception: must remain recognizable)
- Print: Never smaller than 0.25 inches (6.35mm) in any dimension
- Social media profiles: Use at least 400x400px source for best quality
```

### **File Naming Convention**

```
Pattern: GFD-[Type]-[Variant]-[Size].[extension]

Examples:
GFD-Logo-Full-Color.svg           (Standard, no size = vector/scalable)
GFD-Logo-Monochrome-Light-512.png (Specific size variant)
GFD-Icon-Only-1024x1024.png       (Explicit dimensions)
```

## 🎨 Production Workflow

### **Phase 1: DALL-E Generation** (10 minutes)

- Execute prompt from [THE_PERFECT_DALLE_PROMPT.md](./THE_PERFECT_DALLE_PROMPT.md)
- Download 1792x1024 HD output
- Save as `DALLE-Output-Original-[timestamp].png`

### **Phase 2: Initial Assessment** (30 minutes)

- Review against success criteria checklist
- Test at multiple sizes (4096, 1024, 512, 128, 64, 32, 16px)
- Check circular crop behavior
- Verify color extraction (is glow color clean?)
- Decide: Approve / Refine / Regenerate

### **Phase 3: Vectorization** (1-2 hours)

**Tools:** Adobe Illustrator (preferred) or Figma

**Steps:**

1. Import DALL-E output at high resolution
2. Create layers:
   - Background (dark #0d0d0d)
   - Main symbol/icon geometry
   - Glow/accent effects
   - Optional: Animation/interaction guides
3. Trace carefully:
   - Use pen tool for clean geometric paths
   - Convert glow to gradient or radial blur effect
   - Ensure all shapes are closed paths (no gaps)
4. Organize:
   - Group related elements
   - Name layers descriptively
   - Create artboards for each variation
5. Export master:
   - Save as .AI (Illustrator) or .FIG (Figma)
   - Export SVG (web-optimized, <50KB target)
   - Export PNG (4096x4096, transparent background)

### **Phase 4: Color Variants** (1 hour)

From master vector, create:

1. **Full Color** - Original with glow
2. **Monochrome Light** - Replace accent with white (#f5f5f5), adjust glow
3. **Monochrome Dark** - Replace accent with black (#0d0d0d), remove glow
4. **Flat** - Remove gradients/glows, solid fills only

Export each as SVG + PNG (4096x4096)

### **Phase 5: Size Optimization** (1 hour)

Generate all size variants:

**PNG Sizes:** 16, 32, 48, 64, 128, 180, 192, 400, 512, 800, 1024, 1080, 1200, 2560, 4096px

**Optimization:**

- Use ImageOptim (Mac), TinyPNG (web), or Squoosh (web) for compression
- Maintain transparency for all non-social-media variants
- Target: <100KB for 1024px, <500KB for 4096px

**ICO Creation:**

- Combine 16, 32, 48, 64px into multi-resolution favicon.ico
- Tools: IcoFX, GIMP, or online generator

### **Phase 6: Social Media Assets** (2 hours)

**Profile Pictures:**

- Start with Icon-Only version (square, circular-crop safe)
- Export: 1080 (Instagram), 400 (Twitter/LinkedIn), 180 (Facebook), 800 (YouTube)
- Test circular crop at each size (use template overlays)

**Cover Images:**

- Use existing [LinkedIn prompt](../LINKEDIN_COMPANY_COVER_DALLE_PROMPT.md) as reference
- Coordinate logo placement with cover design
- Ensure text/logo safe zones respected
- Export each platform size from Photoshop/Figma

**Post Templates:**

- Create layered PSD/FIG files with logo, brand colors, example layouts
- Include guides for safe zones, text placement, imagery areas

### **Phase 7: Print Assets** (1 hour)

**Color Mode:** Convert to CMYK
**Resolution:** Minimum 300 DPI at actual size
**Bleed:** Add 0.125" (3mm) bleed for all print files
**Format:** PDF/X-1a or PDF/X-4 for professional printing

**Files:**

- Business card (3.5"x2", logo top-left or centered)
- Letterhead (8.5"x11", logo top-left)
- Envelope (#10 standard, logo top-left)

### **Phase 8: Documentation** (2 hours)

**Brand Guidelines Content:**

1. Introduction (brand story, personality, values)
2. Logo Variations (all versions shown with usage context)
3. Clear Space & Sizing (diagrams with measurements)
4. Color Palette (hex/RGB/CMYK/Pantone, accessibility notes)
5. Typography (font families, weights, sizing scales)
6. Correct Usage (DOs - proper backgrounds, sizes, placements)
7. Incorrect Usage (DON'Ts - stretching, recoloring, cluttering)
8. Applications (mockups: website, social, print, apparel)
9. Accessibility Guidelines (WCAG 2.1 AA requirements)
10. Contact & Downloads (where to get assets, who to contact)

**Design:** InDesign or Canva, export as searchable PDF
