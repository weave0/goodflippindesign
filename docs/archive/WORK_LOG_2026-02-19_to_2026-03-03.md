### 🟡 Should Fix

**4. `_worker.js` injects `STRIPE_PUBLISHABLE_KEY` but not `CLERK_PUBLISHABLE_KEY`**

`window.ENV` in worker only exposes `{ STRIPE_PUBLISHABLE_KEY }`. The community portal reads Clerk's key directly from the hardcoded source. Both should be worker-injected.

**5. deploy.yml runs full Puppeteer tests on every `push` to main**

`ci.yml` runs tests on PRs (good, cheap). `deploy.yml` runs on `push: main` AND calls `npm test` (Puppeteer, ~30s). This means every merged PR triggers tests twice. The deploy.yml `pre-deploy` job should either drop `npm test` (trusting CI already ran it) or be narrowed to a pre-deploy lint/build only.

**6. force-deploy verification uses fragile hardcoded content markers**

Verifies deployment by grep-ing for `community-portal.html` in index and `hero-primary-btn` in the portal. If those strings change, verification silently breaks and always passes or always fails.

- Action: Use a version marker (e.g., `<!-- deploy-sha: {{ SHA }} -->`) injected by the workflow and verified in the verify step.

**7. `_headers` CSP: `frame-src` missing `clerk.goodflippinvibes.com`**

`frame-src` only lists `https://js.stripe.com`, `https://hooks.stripe.com`, and `https://accounts.goodflippinvibes.com`. Clerk can also open iframes from `clerk.goodflippinvibes.com` (the FAPI domain). If a popup/embed flow triggers, this could cause blocked frames.

- Verify: Does Clerk embed from `clerk.goodflippinvibes.com` or only from `accounts.*`?

**8. `index.html` is 7,261 lines but copilot-instructions.md says 1,044**

The instructions file is significantly out of date and will give the AI incorrect context about the site's structure and features.

- Action: Update `.github/copilot-instructions.md` to reflect the actual file sizes, features (community portal, donation page, Clerk auth), and current line numbers.

**9. `STATUS.md` and `DASHBOARD.md` dated January 28, 2026**

These documents describe a much earlier state of the project (141/144 tests, no community features, no Clerk, no Cloudflare Worker for Stripe). Any new contributor reading them will have a wrong picture.

- Action: Update or archive these with current feature set and status.
