## Recurring Bloat Patterns to Watch

1. **AI model caches** — ThyOwn, Whisper, CLIP download large models to `C:\Users\brett\.cache\`. Symptom: fills C: silently over weeks. Fix: set `HF_HOME`, `WHISPER_CACHE`, etc. to E: drive.
2. **VS Code workspace storage** — `AppData\Roaming\Code\User\workspaceStorage` = chat history, extension state. Grows unbounded. Periodically run: `code --remove-stale-extension-directories`
3. **node_modules on OneDrive** — OneDrive is syncing full project directories including node_modules. Exclude via OneDrive settings → "Manage backup folders"
4. **Docker images** — `docker system df` returned empty (Docker Desktop not running during audit). Run `docker system prune -a` to free image cache when idle.
5. **Dynamic VHDX growth** — Z: VHDX (171 GB physical) will keep growing with every `npm install`, build artifact, etc. Schedule quarterly `Optimize-VHD` after cleanup runs.

## Governance System — Production Tools (Added March 8, 2026)

Two new tools were created to make this a repeatable, permanent capability rather than a one-time audit:

### 1. Storage Snapshot Script

**File:** [`scripts/storage-snapshot.ps1`](scripts/storage-snapshot.ps1)

Scans all drives, hot-spot directories, and node_modules. Compares to a saved baseline and flags drives that have grown > 10 GB. Writes `storage-snapshot.json` to the GFD root.

```powershell
# Run a snapshot
.\scripts\storage-snapshot.ps1

# Save current state as the new baseline (after a cleanup)
.\scripts\storage-snapshot.ps1 -SetBaseline

# Silent mode (for Task Scheduler — runs in background)
.\scripts\storage-snapshot.ps1 -Silent
```

**Recommended schedule:** Monthly via Task Scheduler:

```powershell
$action  = New-ScheduledTaskAction -Execute 'pwsh.exe' -Argument '-NonInteractive -File "Z:\GFD\scripts\storage-snapshot.ps1" -Silent'
$trigger = New-ScheduledTaskTrigger -Monthly -DaysOfMonth 1 -At '09:00'
Register-ScheduledTask -TaskName 'GFD Storage Snapshot' -Action $action -Trigger $trigger
```

### 2. Admin Portal — Storage Intelligence Panel

**File:** [`admin.html`](admin.html) → Navigation item **13: Storage Intel**

Visualizes `storage-snapshot.json` interactively:

- Drive utilization bars (color-coded: green/yellow/red)
- Growth delta vs baseline (flags >10 GB growth)
- Directory hot-spots table sorted by size
- Pending action items with recoverable GB estimates
- node_modules inventory on Z:

**Workflow:**

1. Run `.\scripts\storage-snapshot.ps1` on WEAVERASUS
2. Open Admin Portal → Storage Intel tab
3. Click **Load Snapshot JSON** → select `storage-snapshot.json`
4. Data is saved to `localStorage` and persists between sessions
