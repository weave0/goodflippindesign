# SKY MONEY Weekly Metrics Dashboard

> Template: Update every Monday morning from GA4, Stripe, Formspree, and admin/health data.
> First measurement baseline: Week of 2026-06-16.

---

## How to Pull Each Number

| Metric                      | Source                                                  | How to pull                                          |
| --------------------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| Support CTA clicks          | GA4 → Events → `donate_cta_click`                       | Last 7 days, by page                                 |
| Sponsor/investor CTA clicks | GA4 → Events → `sponsor_cta_click` or `investor_click`  | Last 7 days, by page                                 |
| Ecosystem link outbound     | GA4 → Events → `outbound_click`                         | Filter by ecosystem-overview.html; group by link URL |
| Formspree inquiries         | formspree.io → Submissions → filter last 7 days         | Note subject/budget tier from form fields            |
| Stripe activity             | Stripe Dashboard → Payments → last 7 days               | Count + total; note one-time vs recurring            |
| GoFundMe                    | GoFundMe → Campaigns → campaign updates                 | Donors + total raised this week                      |
| PayPal.me                   | PayPal → Activity → last 7 days                         | Count + total                                        |
| Admin health score          | goodflippindesign.com/admin.html → Health / Deployments | Ecosystem health %, any red repos                    |
| GA4 sessions (total)        | GA4 → Overview                                          | Sessions + users last 7 days vs prior week           |
| Top pages                   | GA4 → Pages → Sort by sessions                          | Top 5 pages, note any revenue-related pages          |
