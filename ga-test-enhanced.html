⚠️ Note: Google's tag verification tool may take 24-48 hours to detect your tag, even if it's working correctly. This page tests real-time functionality.

How to Verify:

  1. Open browser DevTools (F12 or Right-click → Inspect)
  2. Go to the Network tab
  3. Filter by "google" or look for:
    • gtag/js?id=G-QPPVJM1B60 (script load)
    • g/collect (data sent to Google)
  4. Check the Console tab for any CSP errors
  5. Visit your main site to test there too
Alternative Verification:
  • Install Google Tag Assistant Chrome extension
  • Check Google Analytics Realtime report (shows data within seconds)
  • Wait 24-48 hours for Google's verification tool to detect the tag
