## 🎨 Code Samples

### IPC Handler Example

```javascript
// Main process (main.js)
ipcMain.handle("load-portfolio-data", async () => {
  const dataPath = path.join(__dirname, "../../PORTFOLIO_ANALYSIS.json");
  const data = fs.readFileSync(dataPath, "utf-8");
  return JSON.parse(data);
});
```

### Chart.js Integration

```javascript
// Renderer process (renderer.js)
new Chart(ctx, {
    type: 'doughnut',
    data: {
        labels: projects.map(([name]) => name),
        datasets: [{
            data: projects.map(([, data]) => data.totalSize),
            backgroundColor: ['#8b5cf6', '#10b981', '#fbbf24', ...]
        }]
    }
});
```
